# fdudash

本地优先的复旦仪表盘：HTML 界面与本机 Node.js 服务，提供首页待办、校园信息、课表、eLearning、考试、教室查询、四校区天气与链接站。Tauri 桌面封装后置。

## 启动（全部在 WSL）

```sh
cd fdudash
npm ci
npm test
# 可选：首次浏览器验证
npx playwright install chromium
npm run test:ui
npm start
```

浏览器打开 http://127.0.0.1:5173 。使用其他端口时设置 PORT。服务只绑定本机回环地址，拒绝其他 Host 和跨站请求。不要直接反向代理到公网。

## 当前边界

- 勾选记住账号后，密码使用 Windows DPAPI CurrentUser 加密，保存在 WSL 用户目录 ~/.local/share/fdudash/credentials，文件权限 0600。密文与仓库分离，不使用 localStorage。下次打开页面自动解锁并登录一次，失败不自动重试；Windows 账号变化后不能解锁。取消记住账号仅使用当次凭据。Cookie 只保留在 Node 进程内存，退出登录、重启服务或 30 分钟闲置后清除；退出并忘记账号还会删除已保存密文。本机浏览器与服务进程中的敏感信息仍需要设备本身可信；清空变量不等于保证运行时内存立即擦除。
- 每个浏览器配置独立 CookieJar 与随机凭据文件标识（HttpOnly 持久 Cookie 保存标识）；发往校园系统的 URL 有固定白名单；密码认证失败不自动重试。
- 验证码、双因素认证、旧版 UIS 和研究生课表尚未支持。出现交互认证要求会停止并显示原因。
- 手机浏览器独立连接 UIS 仍受跨域约束。本版不开放局域网访问；手机访问及其本地认证路径后续设计。
- 学期和课程数据结构按 DanXi 当前实现适配；周日起始的教学周映射为周一起始。只查询，不修改校园信息。
- 真实数据仅内存展示，退出清空；没有离线课表缓存。
- 本地保存功能当前针对 WSL + Windows DPAPI，其他系统不可用时不会回退明文存储。清除浏览器 Cookie 会使保存账号的标识丢失，需要重新登录；可手动删除上述凭据目录以清理遗留密文。
- 周课表按截图的 1–14 节（08:00–22:00）布局，课程卡显示名称、教室、起止时间和教师，跨节次课程跨行显示。

## 每周课表与 eLearning

- 课表提供上一周、下一周、本周、周选择与周一至周日日期范围。只渲染所选教学周，合并同周重复课程；同周真实冲突按整组安排并排，不遮挡。日期按北京时间计算。
- 登录 UIS 后点击“连接并读取课程”，本机复用会话；若需要独立票据，使用已保存的本机账号建立 eLearning 会话一次。只读取活动课程与作业列表，不提交作业或修改课程；按 Canvas 分页读取完整列表。
- eLearning 实际访问已验证；自动测试使用虚构课程，个人课程、凭据、会话均不写入仓库。

## 作业列表与多教室安排

- 同一教学班、同一天、同一节次的多教室记录合并成一张课表卡，保留所有教室；不同教学班不合并。
- 点击侧栏 eLearning，或直接打开 /#elearning，登录恢复后自动读取各课程与作业。手动刷新可重新查询；切换侧栏不会重复请求已加载的数据。
- 作业按课程分组，未完成展开，已完成默认折叠。已提交、已批改或豁免归入已完成；缺交、零分缺交和要求重新提交仍在未完成中。无需在线提交的安排单独折叠，未知状态明确标注。截止时间按北京时间显示，逾期不等于完成。
- 自动读取 Canvas 分页；某门课程无权限或读取失败时单独显示错误，不将其误报成无作业。只读，不提交、修改或标记任何作业。
- API 参考：https://developerdocs.instructure.com/services/canvas/resources/assignments 与 https://developerdocs.instructure.com/services/canvas/resources/submissions 。

## 课程中心

- 有未完成作业的课程优先，按最早截止时间排序；未设置截止时间的待办排在有日期的待办之后。没有未完成作业的课程按 Canvas 创建时间倒序；读取失败单独标明。
- 已删除正常页面的演示入口与演示数据，浏览器测试仅通过模拟 API 提供虚构数据。
- 按每门课程实际可见的 Tabs 自动发现模块，不虚构未开放的模块。默认作业，优先排列作业、分数、文件；公告、首页、教学大纲、讨论、教师与助教、学习单元、测验、页面按课程可用情况展示。未知扩展模块保留安全入口并注明不支持摘要。
- 作业含截止日期、提交状态、要求、附件、可见分数和反馈；成绩汇总直接采用 Canvas 返回值，不把未评分当零分。
- 文件提供文件夹、大小、更新时间、搜索与本机下载；PDF、常见图片和纯文本可预览，其他类型下载。文件上限 64 MB；锁定文件遵守平台权限。支持官方 elearning.obs.fudan.edu.cn 对象存储重定向，绝不向其转发 UIS Cookie，文件仅在内存处理，不持久缓存。
- 默认卡片显示最新公告摘要。富文本转为纯文本及安全资源链接，不执行校园内容中的脚本；较长正文可展开。教师模块仅提取教师与助教，不批量复制学生名册。
- 首次加载最多两门课程并发，其他课程模块顺序读取，课程级错误与模块级错误独立展示。页面正文按需读取；不自动启动测验、不提交作业、不标记公告或讨论已读。

## 导航、考试与语言

- elearning 增加可搜索的课程导航，点击快速定位并聚焦课程卡。模块再次点击收起，首次仅展开含未完成任务的模块。右上角 badge 来自平台任务状态，查看、切换和收起均不会清除；刷新读到已完成后才更新。
- 新增考试页面，从教务考试安排接口读取课程、类型、起止时间、地点和备注；已结束考试默认折叠。读取失败与暂无考试明确区分。
- 侧栏顺序为 Dashboard、Timetable、eLearning、Exams、Classrooms、Links。天气通过首页的详细天气入口打开。界面支持简体中文、繁体中文、英文和拉丁语，默认跟随浏览器语言；左下角按钮依次切换并记住偏好。繁体仅转换字形，保留大陆用词及纔、祇形式；时间均为北京时间。
- 语言和侧栏折叠偏好保存在本机 localStorage；凭据仍使用仓库外的 DPAPI 加密文件，绝不进入 localStorage。折叠后保留图标与可访问标签。窄屏侧栏展开为覆盖面板，课表及成绩表仅在自身容器内横向滚动。

## 首页与本机工具

- 默认首页为 dashboard，FDUDash 标识返回首页；FDU 加粗，折叠侧栏使用校徽。欢迎语仅在首页显示，姓名采用仓库外 DPAPI 加密缓存，退出并忘记账号时清除。
- 首页聚合未完成作业、校园卡余额、宿舍电量、校车、教学公告与复旦四校区天气。待办按截止时间排列，倒计时每 30 秒本地更新，不额外请求接口；超过一天显示天数。
- 初始只读取首页所需内容。课表、考试和完整课程模块进入对应页面后才读取，不启动后台全量预抓取。已完成作业按截止时间倒序，缺少截止时间时采用提交时间。
- 天气沿用复旦大气科学系公开接口，首页与天气页共用 15 分钟缓存，保留校方原始预报时段。天气页可选择校区。
- 链接站来自复旦官网在校学生页面及信息化服务公开目录，不读取浏览历史。只保留规范化站点入口，链接在新标签页打开。
- 左下角设置提供登录或退出并忘记账号，以及减少 UI 动画。动画偏好默认跟随系统，可在本机保存。考试区分距开始时间、一小时内即将开始、进行中及已结束。

## 分阶段加载与教室查询

- 首页 TODO 合并未完成作业及未结束的课程考试、水平测试，按截止或开考时间排序；任务列表在卡片内部滚动。公告采用按行排列的两栏布局。
- eLearning 先显示课程和作业，复用本机会话中两分钟内的首页作业缓存；随后发现实际模块并后台读取。点击尚未加载的模块显示加载状态，同一模块请求复用；手动刷新会更新作业。
- 考试来源独立报告读取状态。水平测试读取考试安排，不执行报名、缴费或准考证打印；原页入口可供用户自行操作。
- Classrooms 按教学楼、日期查询，支持连续起止节次空闲筛选、查看全部教室、搜索教室及课程、展开完整 14 节课程安排。空闲不代表教室开放或允许进入。
- 教室服务优先直连校园地址，失败后可通过独立 UIS 认证的 WebVPN 读取固定教室服务；不提供任意网址代理。结果短时缓存在进程内存中。
- 繁体字形表由 OpenCC-JS 生成，许可证见 `licenses/OpenCC-JS.txt`；运行 `npm run generate:traditional` 可重新生成。界面在本机加载转换表，不调用远程翻译服务。
